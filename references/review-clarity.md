# ZQM Bounty Hub — Review Clarity Reference

Clarity rules for Review-Worthy findings and suggestions.

## Findings
A review-worthy finding should contain:
- Problem summary
- Impact statement
- Reproduction steps or evidence path
- Source/target_id
- Sandbox command + runtime, if applicable

A finding should NOT:
- Include suggestions that move the target state unless clearly marked as hypothetical
- Include executable-only sandbox output without source
- Suggest outside scope without explicit authorization note

## Suggestions
A review-worthy suggestion should:
- Suggest more than one candidate when possible
- Include command/path, runtime, and configuration values
- Include translation-link mapping and memory-file checks when applicable
- Clearly mark sandbox-only content

A suggestion should NOT:
- Over-restrict without documented rationale
- Suggest network tests without prior authorization path
- Include credentials or secrets in example output
